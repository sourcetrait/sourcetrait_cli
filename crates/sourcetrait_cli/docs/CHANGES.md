## v0.0.3
### srctrait box
Podman container and management CLI. Intended as a tooling and data analysis
environment. 

The container image is layered on top of an excellent distro for this sort of
work: `fedora-toolbox`. Additionally includes claude-code and various tools for
use by both the user and the AI agent.

Runs an SSH daemon once started. You SSH in and away you go.
